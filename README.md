# Claupt

Free browser-based tools that help people prepare safer, smaller, and clearer inputs before using AI.

## What we build

- Estimate AI tokens and prompt cost
- Clean and split long text for prompts and RAG
- Convert PDF and DOCX files into reviewable Markdown
- Compress JSON and remove code comments
- Review common personal-data patterns before sharing text with AI
